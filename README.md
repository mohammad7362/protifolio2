# Zeinab ALMasry Portfolio

A professional accounting portfolio website built with **HTML**, **CSS**, and **JavaScript**.

## Project Files
- `index.html` — main website content
- `style.css` — styling and responsive design
- `script.js` — navigation and scroll effects

## How to Use
### Open directly
Open `index.html` in your browser.

### Edit content
- Change text in `index.html`
- Update colors/layout in `style.css`
- Adjust interactivity in `script.js`

## Suggested VS Code workflow
Use **Live Server** for quick preview while editing.
